# Hemp

A double crop plant that can spawn only on Jungle biomes

Mainly used as alternative source of strings

It naturally spawn as a single block plant but once planted it will grow to be a two blocks plant

When harvested a mature hemp plant it will drop <ItemLink id="vintagetech:hemp"/>
